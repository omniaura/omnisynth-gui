# Omnisynth GUI

This is the GUI for OmniSynth.

To install the required project dependencies,
use Python 3.11 or newer and run `python project-setup.py` from a virtual
environment. The setup expects the sibling `../omnisynth-dev/omnisynth` source
tree and the Python `build` package. Pillow 13 or newer is required for the
patched image decoder; Python 3.10 cannot install that dependency.
